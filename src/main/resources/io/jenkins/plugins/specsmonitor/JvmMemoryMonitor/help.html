Shows the free memory of the Java virtual machine running on each node, for example 1.6 GiB. Sizes use binary units (1 GiB = 1024 MiB).

Free memory is the maximum heap size (-Xmx) minus the heap currently in use. Hover over the value to see how much is free out of the maximum, for example 1.6 GiB free of 2 GiB. These figures are a snapshot taken when the monitor last refreshed.
