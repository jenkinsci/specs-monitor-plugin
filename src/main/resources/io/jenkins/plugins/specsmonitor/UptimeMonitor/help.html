Shows how long the machine of each node has been running since its last boot, for example 3d 4h. Hover over the value to see the full duration.

The information is read on the node itself: PowerShell on Windows, /proc/uptime on Linux, and sysctl kern.boottime on macOS. On other systems, or if the lookup fails, the uptime of the agent process is shown instead. The value is a snapshot taken when the monitor last refreshed.
