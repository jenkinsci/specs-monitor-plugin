Shows the remoting version of each node, for example 3355.3357. Hover over the value to see the full version, for example 3355.3357.v931d3c992987.

If a node runs an older remoting version than the controller, the value is shown in yellow with a warning symbol.

The information is read on the node itself, so it reports the remoting library the agent is actually running. This makes outdated agent.jar files easy to spot.
