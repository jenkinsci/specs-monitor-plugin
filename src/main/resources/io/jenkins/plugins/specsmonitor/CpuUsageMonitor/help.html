Shows the CPU usage of each node's machine, for example 37%. The usage is measured on the node itself over one second, each time the monitor refreshes, so it is a snapshot and not an average over the whole interval. Usage at or above a configurable percentage (default 99%) is shown in Jenkins' warning style.

Hover over the value to see more detail, for example System: 37% • JVM: 2%:

  • System: the CPU usage of the whole machine, all processes included.
  • JVM: the share used by the Jenkins agent process itself. Build steps run as separate processes and are not included, so a high system value with a low JVM value means builds or other programs are using the CPU.

Inside a container, the usage is relative to the container's CPU limit. If the Java virtual machine cannot measure the usage, N/A is shown.
