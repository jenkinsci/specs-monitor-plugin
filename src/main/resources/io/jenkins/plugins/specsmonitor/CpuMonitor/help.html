Shows the CPU model and the number of hardware threads (logical processors) of each node, for example i7-13700K (16 threads).

The information is read on the node itself: PowerShell on Windows, lscpu or /proc/cpuinfo on Linux, and sysctl on macOS. Long vendor strings such as (R), (TM), clock speed and Intel are removed for readability. If the CPU model cannot be determined (for example on AIX or Solaris), N/A is shown.

The tooltip shows the full CPU name. If the name does not contain a clock speed, the speed reported by the node is appended, for example @ 4.85GHz. This is the maximum frequency where available, otherwise the nominal or current frequency. Some nodes, such as Apple Silicon Macs and many ARM machines, report no frequency at all.

The thread count is the number of processors available to the Java process. It can be lower than the hardware value on nodes with CPU limits, such as containers.
