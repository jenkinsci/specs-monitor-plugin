Shows the free or available memory (RAM) of each node, for example 15.6 GiB. Sizes use binary units (1 GiB = 1024 MiB).

The information is read on the node itself: PowerShell on Windows, /proc/meminfo on Linux, and sysctl on macOS. On other systems, or if the lookup fails, the value reported by the Java virtual machine is used, or N/A if that is unavailable.

Hover over the value to see how much memory is free out of the total, for example 43.5 GiB free of 63.7 GiB. If the operating system reports different values for available memory (usable by applications without swapping, including reclaimable caches) and free memory (completely unused), both are shown. These figures are a snapshot taken when the monitor last refreshed. On macOS the available value is an approximation (free, inactive and speculative pages).

On Linux the total value is the memory the kernel can use, which is slightly less than the installed amount. Inside a container, the value reported by the JVM may be the container limit.
