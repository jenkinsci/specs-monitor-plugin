Shows the total physical memory (RAM) of each node, for example 15.6 GiB. Sizes use binary units (1 GiB = 1024 MiB).

The information is read on the node itself: PowerShell on Windows, /proc/meminfo on Linux, and sysctl on macOS. On other systems, or if the lookup fails, the value reported by the Java virtual machine is used, or N/A if that is unavailable.

On Linux the value is the memory the kernel can use, which is slightly less than the installed amount. Inside a container, the value reported by the JVM may be the container limit.
