Shows the version of the Java virtual machine running on each node, for example 25.0.4.1. Hover over the value to see the full version, for example 25.0.4.1+1-LTS.

If a node runs an older Java feature release than the controller (for example Java 17 while the controller runs Java 21), the value is shown in yellow with a warning symbol.

The information is read on the node itself, so it reports the JVM of the agent process.
